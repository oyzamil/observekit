observekit — live demos

Every method below is wired to a real observekit watcher. Trigger the action, watch the log, hit Replay to reset and re-register. Each card also shows the exact call you'd write to use that function yourself.

observekit.element / selector


        

          
Usage

          
const watcher = observekit.selector('.demo-item', {
  add: (els) => console.log('added', els),
  remove: (els) => console.log('removed', els),
}, { existing: false });

// later, to stop watching:
watcher.disconnect();

        

      


      

        
observekit.element — matched by text

        
watcher is scoped to button +
          { text: 'Archive' }
          — only a button whose text is exactly "Archive" fires, the "Delete" button never does

        

          
          
          
          
        

        

        

        

        

          
Usage

          
const watcher = observekit.element('button', {
  add: (els) => els.forEach((el) => console.log('matched', el.textContent)),
  remove: (els) => console.log('removed', els.length),
}, { text: 'Archive', existing: false });

watcher.disconnect();

observekit.text

        

          type below — uses debounce: 300ms, not throttle. debounce fits typing better: you want the
          settled final value once typing pauses, not a callback firing every N ms mid-keystroke (that's what
          throttle would give you, and it'd fire with half-typed words).
        

        

          initial text

        

        

          
        

        

          
Usage

          
const watcher = observekit.text(
  document.getElementById('text-target'),
  (els) => console.log('settled ->', els[0].textContent),
  { debounce: 300 },
);

watcher.disconnect();

        

      


      

        
observekit.resize (+ start / end)

        

          
          
        

        
drag bottom-right corner to resize manually — watch start/end fire
          separately
          from the per-tick resize log

        

          

          

        

        

        

          
Usage

          
const watcher = observekit.resize(
  document.getElementById('resize-target'),
  (entries) => console.log('tick size ->', entries[0].contentRect),
  {
    onStart: () => console.log('resize START'),
    onEnd: (entries) => console.log('resize END', entries[0].contentRect),
  },
);

watcher.disconnect();

Options: debounce / once / timeout / signal

        

          
          
          
          
        

        

        

        

          

            
Usage — debounce

            
observekit.selector('.opt-item', (els) => {
  console.log('batch:', els.length);
}, { existing: false, debounce: 150 });

          

          

            
Usage — once

            
observekit.selector('.opt-once', (els) => {
  console.log('fired once for', els.length);
}, { existing: false, once: true });

          

          

            
Usage — signal

            
const ctrl = new AbortController();
observekit.selector('.opt-abort', (els) => {
  console.log('fired for', els.length);
}, { existing: false, signal: ctrl.signal });

ctrl.abort(); // stops the watcher
